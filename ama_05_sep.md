1. **Which command is used to check the current working directory?**  
   `pwd` — Prints the current working directory.

2. **What are the different ways to apply CSS to an HTML document?**  
   - Inline CSS
   - Internal CSS
   - External CSS

3. **What is a correlated subquery in SQL?**  
   A subquery that depends on the outer query and executes once for each outer row.

4. **Which command is used to check the remote repository in Git?**  
   `git remote -v`

5. **What are the different input types in HTML?**  
   `text`, `password`, `email`, `number`, `radio`, `checkbox`, `date`, `file`, `submit`, etc.

6. **How does CSS margin work when two values are provided?**  
   `margin: 10px 20px;` → **10px top/bottom**, **20px left/right**.

7. **What are the different types of collections in Python?**  
   - List
   - Tuple
   - Set
   - Dictionary

8. **What is the difference between `rem` and `em` in CSS?**  
   - `rem` → Based on the root (`html`) font size.
   - `em` → Based on the parent/current element's font size.

9. **How do we create a table in HTML, and what are the different types of table elements?**  
   Use `<table>`, with elements like:
   - `<tr>` → Table row
   - `<th>` → Table heading
   - `<td>` → Table data
   - `<thead>` → Table header section
   - `<tbody>` → Table body section
   - `<tfoot>` → Table footer section

10. **What is inheritance in OOP?**  
    A child class gets properties and methods from a parent class.

11. **What is the difference between encapsulation and abstraction?**  
    - **Encapsulation** → Bundles data and methods together and controls access.
    - **Abstraction** → Hides implementation details and shows only necessary features.

12. **What are the different CSS transform properties?**  
    `translate()`, `rotate()`, `scale()`, `skew()`, `matrix()`.

13. **If `flex-direction` is set to `row`, how do the main axis and cross axis work?**  
    - **Main axis** → Horizontal (left → right)
    - **Cross axis** → Vertical (top → bottom)
