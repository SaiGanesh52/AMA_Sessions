### 1. Which command is used to change the permission of a file?
   - `chmod` is used to change the permissions of a file.

### 2. What is Promise.race()?
   - `Promise.race()` returns the result of the first promise that settles, whether fulfilled or rejected.

### 3. What are template literals?
   - Template literals are strings enclosed in backticks (`) that allow embedded expressions using `${}`.

### 4. Which CLI command is used to change the directory?
   - `cd` is used to change the current directory.

### 5. What is the TDZ?
   - TDZ (Temporal Dead Zone) is the period between entering a scope and declaring a `let` or `const` variable where it cannot be accessed.

### 6. What happens if all promises passed to Promise.any() fail?
   - `Promise.any()` rejects with an `AggregateError` when all promises fail.

### 7. What is a callback function?
   - A callback function is a function passed as an argument to another function to be executed later.

### 8. What is the difference between 400 and 500 error status codes?
   - `400` indicates a client-side request error, while `500` indicates a server-side error.

### 9. What is the difference between var, let, and const?
   - `var` is function-scoped, while `let` and `const` are block-scoped, and `const` cannot be reassigned.

### 10. In asynchronous programming, why do we use promises instead of callbacks?
      Promises make asynchronous code easier to read, handle errors, 
      and avoid deeply nested callback structures.

### 11. What is a higher-order function?
     A higher-order function is a function that takes another function as an argument or returns a function.

### 12. What is a closure?
      A closure is a function that remembers and can access variables from its outer scope even after 
      the outer function has finished.

### 13. What is the DOM?
     DOM (Document Object Model) is a programming interface that represents an HTML document 
     as a tree of objects.
