1. **What is the difference between flatMap() and map()?**  
   `map()` transforms each element and returns a new array, while `flatMap()` transforms each element and then flattens the result by one level.

2. **What is the find command in CLI?**  
   The `find` command is used in CLI to search for files and directories based on conditions such as name, type, or size.

3. **What is innerHTML in JavaScript?**  
   `innerHTML` is a property used to get or change the HTML content inside an element.

4. **What is the map() method in JavaScript?**  
   The `map()` method creates a new array by applying a function to every element of an existing array.

5. **What are LIMIT and OFFSET in SQL?**  
   `LIMIT` specifies the maximum number of rows to return, while `OFFSET` specifies the number of rows to skip.

6. **How do you create a user in SQL?**  
   A user can be created using the `CREATE USER` statement, such as `CREATE USER username WITH PASSWORD 'password';`.

7. **What is reduce() in JavaScript?**  
   The `reduce()` method processes array elements and combines them into a single value using an accumulator.

8. **What are the different data types in JavaScript?**  
   JavaScript data types are `String`, `Number`, `BigInt`, `Boolean`, `Undefined`, `Null`, `Symbol`, and `Object`.

9. **What is promise chaining?**  
   Promise chaining is the process of connecting multiple `.then()` methods so asynchronous operations execute sequentially.

10. **What is an event listener?**  
    An event listener is a function that waits for a specific event on an element and executes when that event occurs.

11. **What are abstraction and encapsulation?**  
    Abstraction hides unnecessary implementation details, while encapsulation bundles data and methods together and controls access to them.

12. **What is a decorator?**  
    A decorator is a design pattern or feature used to add or modify behavior of a class, method, or object without changing its original code.

13. **What is the JavaScript engine used by Chrome?**  
    Google Chrome uses the **V8 JavaScript engine** to execute JavaScript code.
